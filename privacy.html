プライバシーポリシー

Discord Music Playlistで扱うデータと、その利用目的を説明します。

1. 取得する情報と目的

  • Discord：指定投稿と返信の本文、メッセージID、投稿日時、Bot投稿等を除外するための属性を取得し、音楽リンクを抽出します。API応答に投稿者情報が含まれる場合がありますが、投稿者名や本文を処理記録には保存しません。
  • YouTube：認可したアカウントのチャンネル識別情報、指定プレイリストの情報と動画IDを取得し、所有者確認・重複確認・動画追加に使います。
  • 認証情報：GoogleのOAuthクライアント情報・更新用トークン、Discord Botトークンを、認可したAPI呼び出しと定期実行のために使います。
  • Spotify：投稿された曲リンクの曲IDと元投稿IDを確認待ちとして記録します。現在、Spotifyアカウントのログイン情報は取得しません。

2. 保存場所と保存期間

現在は管理者のWindows PCで処理し、認証情報をWindowsユーザーにひも付くDPAPIで暗号化して保存します。初期設定時の平文トークンファイルは削除しました。以前のGitHub Actions Secretsやバックアップ等の残存コピーは別途整理対象です。現在のクラウド用ワークフローは認証情報を使用しません。

現在の動画ID、処理済み記録、確認待ちの曲ID・投稿IDは管理者のWindows PCに保存し、重複防止と運用確認に利用します。旧運用の記録は非公開GitHubリポジトリにも残っています。運用に必要な期間保持します。更新前の記録はGitの履歴にも残るため、現在のファイルを消すだけでは過去の記録は削除されません。

実行ログには件数やエラーの種類を記録します。投稿本文やトークンを出力しない設計です。現在の実行ログは管理者のPCに保存し、一定サイズで入れ替えます。旧GitHub実行ログの保持期間はGitHubの設定に従います。

3. 外部サービスへの送信

現在の同期処理は管理者のWindows PCで行います。Discordの本文はリンク抽出のため一時的に実行環境で扱います。YouTubeへの追加時には動画IDとプレイリストIDをGoogleへ送信します。元のDiscord本文や投稿者名をプレイリストの説明に転載しません。Discordの接続イベントはBotに許可されたチャンネルから届く場合がありますが、同期対象外の投稿は処理対象にせず、本文をログに保存しません。閲覧権限の範囲はDiscord側で管理します。

データの販売、広告配信、生成AIの学習・推論への送信は行いません。保存・実行のために利用するGitHubと、APIを提供する各サービスでは、それぞれの方針に基づく処理が行われます。

4. Googleユーザーデータ

Googleから取得した情報は、管理者が認可したプレイリスト同期とその運用確認のためにのみ使います。Google APIから受け取った情報の使用・他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

このツールはYouTube API Servicesを利用します。Googleプライバシーポリシーも参照してください。

5. 連携解除と削除

管理者はGoogleアカウントの接続管理で本アプリへの認可を取り消せます。Discord Botの削除やトークンの無効化でも、その接続を停止できます。認可の取り消しだけでは、追加済みの曲やGitHub・ローカルPCの記録は自動削除されません。

保存情報の削除は運営者へ依頼してください。現在のファイル、Gitの履歴、ローカルファイル、ログ等の保存場所を確認して対応します。プレイリスト上の曲は所有者が手動で削除できます。

6. この説明サイト

このサイト独自のアクセス解析、広告、入力フォーム、Cookieを使う機能は設置していません。ホスティング提供者GitHubが、配信・安全性確保等のためIPアドレスなどを処理することがあります。GitHubのプライバシーに関する声明を参照してください。
